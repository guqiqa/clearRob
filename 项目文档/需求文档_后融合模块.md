## 1. 模块定位与职责边界

### 1.1 定位

`fusion_engine` 是系统的感知融合模块，将视觉 2D 检测框与 LiDAR 3D 点云进行空间关联，产出两个核心输出：
1. **`fusion/3d_target`**：融合后的 3D 目标信息+告警 → master_controller（调度干预）
2. **`fusion/obstacle/decision`**：避障决策（绕行/等待/减速）→ path_planner（局部重规划）

**物理隔离：vision_detector 不直接向 path_planner 发布任何 Topic。本模块是视觉信息到达路径规划模块的唯一通道。所有视觉 2D 检测框必须先经过本模块的 2D→3D 空间关联，转化为 `fusion/obstacle/decision` 或 `fusion/3d_target` 后，方可被下游模块消费。**

### 1.2 职责边界

| 属于本模块 | 不属于本模块 |
|-----------|-------------|
| 2D 检测框 → 3D 点云空间关联 | 2D 检测（vision_detector 负责） |
| 3D 目标位置/尺寸/类别估算 | 3D 点云预处理（lidar_perception 负责） |
| 障碍物分类判定（绕行/清扫/等待） | 路径规划执行（path_planner 负责） |
| 视觉超时降级为纯 LiDAR 模式 | — |
| **物理隔离**：作为视觉信息到达 path_planner 的唯一通道，确保所有 2D 检测框经 2D→3D 空间关联后才下发 | vision_detector 直接向 path_planner 发布 Topic（架构禁止） |

## 3. 功能需求详述

### 3.1 2D 检测框 → 点云映射

**输入：** `vision/detect/list`（2D 像素坐标 + **可选 depth_m**）+ `lidar/scan/pointcloud`（3D 点云）

**深度获取优先级（从高到低）：**
```
1. Detection.depth_m > 0  → 直接使用（来自深度相机的真实距离，最优）
2. LiDAR 点云投影匹配    → bbox 区域内 ≥5 个 LiDAR 点时使用点云中位深度
3. bbox 面积启发式       → 无 LiDAR 匹配时使用 _estimate_distance_from_area()
```

**映射流程（depth_m 路径，优先）：**
```
当 Detection.depth_m > 0 时：
1. 跳过 LiDAR 点云投影 → 图像平面
2. 使用完整针孔相机模型反投影到 3D：
   X = (cx_pix - cx) * depth_m / fx
   Y = (cy_pix - cy) * depth_m / fy
   Z = depth_m
   其中 (cx_pix, cy_pix) 为检测框中心像素坐标
3. 将相机坐标系 3D 点通过 T_camera_lidar 变换到 LiDAR 坐标系
4. 在 LiDAR obstacle_list 中进行角度+距离验证匹配（同常规流程）
```

**映射流程（LiDAR 投影路径，depth_m=0 时回退）：**
```
1. 坐标对齐：确保视觉帧与 LiDAR 帧的时间戳在 tolerance_window (50ms) 内
2. 相机内参投影：将 3D 点云投影至图像平面
   - 已知：相机内参矩阵 K，外参 T_camera_lidar（LiDAR → Camera 坐标变换）
   - 投影：pixel = K × T_camera_lidar × point_3d
3. 对于每个 2D 检测框 (x1,y1,x2,y2)，收集所有投影到该区域的 3D 点
4. 过滤：只保留深度值 (z) 在 [min_depth, max_depth] 范围内的点（默认 0.3m~30m）
```

**投影分辨率匹配（LiDAR 路径）：**
- LiDAR 点云经 VoxelGrid 下采样后，投影到图像的密度有限
- 对于 2D 框内 3D 点数量 < 5 的情况：使用 bbox 面积启发式估算距离
- 对于 2D 框内 3D 点数量 ≥ 5 的情况：使用点云的 3D 中位值 + MAD（中位绝对偏差）稳健估算位置和尺寸

### 3.2 空间关联匹配

**输入：** 视觉检测列表（2D 框 + 类别 + 置信度）+ LiDAR 障碍物列表（3D 位置 + 尺寸 + distance）。

**匹配策略：**
```
对于每个视觉检测框（投影到 3D 空间后）：
  1. 计算视觉投影中心点（框内所有 LiDAR 点云的中位坐标）
  2. 在 LiDAR obstacle_list 中搜索最近邻（欧式距离 < 1.0m 的障碍物）
  3. 若找到匹配 → 关联成功，输出 Fusion3DTarget 并补充 LiDAR 尺寸信息
  4. 若未找到匹配 → 视觉独立目标（如远处物体 LiDAR 未扫描到），仅用视觉估算距离发布
```

**未匹配的 LiDAR 障碍物处理：** 直接转发为 `fusion/obstacle/decision`（action=PASS），不产生 `fusion/3d_target`（无类别信息）。

### 3.3 避障分类判定

**联合判定规则（视觉类别 + LiDAR 三维尺寸）：**

| 视觉类别 | 条件 | fusion/obstacle/decision.action | 说明 |
|----------|------|-------------------------------|------|
| obstacle | LiDAR 尺寸 > 0.2m 或距离 < 3m | DETOUR（偏移量 = 障碍物宽度/2 + 0.5m） | 大型非垃圾障碍物（含车辆），绕过 |
| obstacle | LiDAR 尺寸 ≤ 0.2m（小件） | SLOW（减速比 0.5） | 小块障碍物，减速通过 |
| pedestrian | 任意 LiDAR 匹配 | WAIT（等待时长 = 5s，之后重评估） | 动态目标，优先等待 |
| pedestrian | LiDAR 匹配 + 快速靠近（velocity > 1m/s） | WAIT（等待时长 = 10s）+ 发布 Fusion3DTarget(alert_level=CRITICAL) | 快速奔跑的行人/动物，紧急等待 + 主控告警 |
| recyclable | LiDAR 尺寸 < 0.3m | PASS（不清扫也不绕行，由清扫模块清扫） | 小件可回收垃圾，正常碾压→清扫 |
| recyclable | LiDAR 尺寸 ≥ 0.3m（大纸箱等） | SLOW（减速比 0.3）+ 发布 Fusion3DTarget（通知清扫模块需大吸力） | 大件垃圾先减速再清扫 |
| kitchen_waste | 任意 | PASS | 交由清扫模块处理 |
| hazardous | 任意 | PASS | 交由清扫模块单独收集 |
| other_waste | 任意 | PASS | 交由清扫模块正常清扫 |
| green_waste | 任意 | PASS | 交由清扫模块吸扫 |
| stain（污渍） | 任意 | PASS | 交由清扫模块重拖 |
| stain（积水） | LiDAR 投影面积 > 0.5m² | DETOUR（绕行偏移 = 积水直径 + 0.5m） | 大面积积水绕行 |
| stain（积水） | LiDAR 投影面积 ≤ 0.5m² | SLOW（减速比 0.5） | 小面积积水减速通过 |
| 仅 LiDAR 障碍物（无视觉匹配） | 尺寸 ≤ 0.1m | PASS（小件忽略） | 可能是噪声或极小的地面起伏 |
| 仅 LiDAR 障碍物（无视觉匹配） | 尺寸 > 0.1m | DETOUR（基于障碍物包围盒） | 未知障碍物，保守绕行 |

**决策合并：** 如果同一帧有多个决策目标，按优先级 WAIT > DETOUR > SLOW > PASS 合并为一个最终决策（最保守策略）。

### 3.4 3D 目标告警发布

**`fusion/3d_target` 发布条件：**

| 告警级别 | 触发条件 | 示例 |
|----------|---------|------|
| INFO (0) | 所有成功关联的视觉+LiDAR 目标 | 常规垃圾检测，master_controller 仅记录 |
| WARN (1) | obstacle + LiDAR 确认 + 距离 < 5m | 需要路径规划注意的障碍物（含车辆） |
| CRITICAL (2) | pedestrian + 快速靠近（>1m/s）+ 距离 < 3m | 需 master_controller 立即调度干预 |

**发布频率：** 每帧最多发布 10 个 3D 目标（INFO 级别），WARN/CRITICAL 无限制。

### 3.5 视觉超时降级

**触发条件：** `vision/detect/list` 超时 > 2s 无新帧

**降级行为：**
1. 进入纯 LiDAR 模式：`fusion/status.status = 1`（降级）
2. 仅转发 `lidar/obstacle/list` 中的障碍物为 `fusion/obstacle/decision`（action 基于 LiDAR 尺寸判断，无视觉类别）
3. 停止发布 `fusion/3d_target`（无类别信息无法关联）
4. `fusion/status.status_text = "vision_timeout: pure_lidar_mode"`

**恢复条件：** `vision/detect/list` 恢复 > 3s 连续有帧

## 4. 配置参数（ROS2 Parameter YAML）

```yaml
fusion_engine:
  ros__parameters:
    # 时间同步
    tolerance_window_ms: 50              # 视觉-LiDAR 帧时间戳容忍窗口 (ms)
    
    # 相机外参 (LiDAR → Camera)
    T_camera_lidar:                      # 4×4 变换矩阵
      translation: [0.1, 0.0, 0.3]       # x, y, z (m)
      rotation: [0.0, 0.0, 0.0, 1.0]    # 四元数 x, y, z, w
    
    # 相机内参 (需根据实际相机标定)
    camera_intrinsics:
      fx: 600.0                          # 焦距 X (像素)
      fy: 600.0                          # 焦距 Y (像素)
      cx: 640.0                          # 主点 X (像素)
      cy: 360.0                          # 主点 Y (像素)
      width: 1280                        # 图像宽度
      height: 720                        # 图像高度
    
    # 空间关联
    depth_range_min: 0.3                 # 最小有效深度 (m)
    depth_range_max: 30.0                # 最大有效深度 (m)
    min_points_in_bbox: 5                # 框内最小点数（低于此值为粗略估算）
    visual_lidar_assoc_max_dist: 1.0    # 视觉-LiDAR 关联最大距离 (m)
    
    # 避障判定
    large_trash_size_threshold: 0.3      # 大件垃圾尺寸阈值 (m)（需减速）
    water_area_detour_threshold: 0.5     # 积水绕行面积阈值 (m²)
    detour_safety_margin: 0.5            # 绕行安全距离 (m)
    pedestrian_default_wait_s: 5.0       # 行人默认等待时长 (s)
    pedestrian_rush_wait_s: 10.0         # 快速靠近行人等待时长 (s)
    pedestrian_rush_velocity: 1.0        # 快速靠近判定速度 (m/s)
    critical_distance: 3.0               # CRITICAL 告警距离阈值 (m)
    
    # 降级
    vision_timeout_s: 2.0                # 视觉超时触发降级 (s)
    vision_recovery_s: 3.0               # 视觉恢复观察时长 (s)
    max_fusion_targets_per_frame: 10     # 单帧最大 INFO 级 3D 目标数
```

## 5. 异常处理

| 故障场景 | 检测方式 | 响应行为 |
|----------|----------|----------|
| 视觉 Topic 超时 | `vision/detect/list` > 2s 无帧 | 纯 LiDAR 降级（见 3.5） |
| LiDAR 点云超时 | `lidar/scan/pointcloud` > 2s 无帧 | 仅用视觉检测（不发布 obstacle/decision），发布 status=1（降级） |
| LiDAR 障碍物超时 | `lidar/obstacle/list` > 2s 无帧 | 仅用 2D 检测框估算距离（基于像素面积反推，误差较大），发布 status=1 |
| 两个输入同时超时 | 视觉+LiDAR 均 > 5s 无帧 | status=2（故障），停止所有输出，通知 master_controller |
| 连续无关联 | 连续 30s 无任何 visual-lidar 匹配成功 | 可能为外参漂移，发布 WARN |

## 6. 关键交互序列

### 6.1 垃圾检测→避障决策 完整流

```
vision_detector ── detect/list ──→ fusion_engine ←── lidar/scan/pointcloud ── lidar_perception
                    (2D bbox)         │              (3D 点云)
                                      │←── lidar/obstacle/list ── lidar_perception
                                      │
                         相机内参投影 (3D点云→图像平面)
                         收集 bbox 内的 3D 点
                         空间关联匹配 (视觉↔LiDAR障碍物)
                         联合判定 (类别+尺寸)
                                      │
                         ┌────────────┼────────────┐
                         ↓                         ↓
              fusion/obstacle/decision     fusion/3d_target
              (DETOUR/SLOW/WAIT/PASS)     (INFO/WARN/CRITICAL)
                         ↓                         ↓
                   path_planner              master_controller
              (局部避障重规划)             (调度干预/告警记录)
```

### 6.2 视觉超时降级→恢复

```
t=0: vision/detect/list 正常流入
t=0.5: 最后一帧视觉数据
t=2.5: vision_timeout_s 到期
       → fusion/status(status=1, "vision_timeout: pure_lidar_mode")
       → 仅发布 fusion/obstacle/decision（基于 LiDAR 尺寸）
       → 停止发布 fusion/3d_target
t=5.0: vision/detect/list 恢复正常
t=8.0: vision_recovery_s 到期
       → fusion/status(status=0)
       → 全功能恢复
```

## 7. 开发里程碑

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| M1: 基础融合 | 2D→3D 投影 + 空间关联 + Fusion3DTarget 发布 | 基础融合链路 |
| M2: 避障决策 | 联合判定规则 + FusionDecision 发布 | 避障决策可用 |

| M4: 降级 | 视觉/LiDAR 超时降级与恢复 | 鲁棒性达标 |
