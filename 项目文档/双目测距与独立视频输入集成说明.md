# 双目测距与独立视频输入集成说明

版本：V0.1（2026-08-19）

## 1. 设计边界

视频输入、视觉识别和双目测距是三个独立模块。`video_input` 只负责把相机驱动提供的图像转换为稳定的 ROS2 图像话题；`vision_detector` 消费 RGB 话题完成识别；`stereo_depth` 消费左右目话题完成 SLAM 建图所需的深度图和稀疏点云。

双目深度只服务于 SLAM/建图和定位，不接入避障决策。避障输入仍由毫米波雷达及其融合链路提供。视觉检测可以选择从深度图采样 `Detection.depth_m`，但不能替代毫米波雷达的避障判定。

```text
S90cam-service.service / Hobot camera pipeline
              |
              v
        video_input
       /     |      \
      v      v       v
 RGB topic  left    right
      |       \     /
      v        stereo_depth ----> SLAM depth / sparse points
 vision_detector
```

## 2. ROS2 接口契约

`video_input` 发布以下稳定话题，实际相机源话题通过参数配置，不写入识别或测距节点：

| 话题 | 类型 | 使用方 |
| --- | --- | --- |
| `sensor/camera/image_raw` | `sensor_msgs/msg/Image` | `vision_detector` |
| `sensor/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 视觉/深度内参 |
| `sensor/stereo/left/image_rect` | `sensor_msgs/msg/Image` | `stereo_depth` |
| `sensor/stereo/right/image_rect` | `sensor_msgs/msg/Image` | `stereo_depth` |
| `sensor/stereo/left/camera_info` | `sensor_msgs/msg/CameraInfo` | `stereo_depth` |
| `sensor/stereo/right/camera_info` | `sensor_msgs/msg/CameraInfo` | `stereo_depth` |

`stereo_depth` 发布 `sensor/stereo/depth/image_raw`、`sensor/stereo/disparity`、`sensor/stereo/points` 和 `sensor/stereo/distance`，并提供 `stereo_depth/get_distance`、`/health`、`/latest`、`/depth.pgm` 和 `/ws`。默认计算参数为 640x360、5 FPS、StereoSGBM 和稀疏点云，适配 QSM602HA-GL 的算力限制。

## 3. 板端实测状态

2026-08-19 在 `root@192.168.8.143` 重试结果：

- `S90cam-service.service`：`active (running)`，启动命令为 `/usr/hobot/bin/cam-service -C5 3 5 3 -s4 2 4 2 -i6 -V6`。
- ROS2 环境可用，但 `ros2 topic list` 只有 `/parameter_events` 和 `/rosout`，相机服务没有直接发布 ROS2 图像。
- `camera-preview-server:8080` 可以持续输出 H.264，证明相机 pipeline 有视频输出；该接口当前是单路预览流，不提供左右目 `sensor_msgs/Image` 和标定参数。
- `ros2 run stereo_depth stereo_depth_node` 返回 `Package 'stereo_depth' not found`。因此本次不能宣称已经产生深度结果。
- 板端已有 `/root/cleaning_robot_ws` 和 `colcon`，但当前工作区没有 `video_input`、`stereo_depth` 包。

## 4. 正式部署顺序

1. 从相机 pipeline 或厂商 ROS2 驱动取得左右目原始帧、时间戳和 `CameraInfo`；不能把 `/live.h264` 直接当作双目输入。
2. 将源话题写入 `ROS2-clearRob/src/video_input/config/video_input.yaml` 的 `source_*_topic`，确认左右目分辨率、编码和时间戳一致。
3. 在板端工作区加入 `video_input`、`stereo_depth` 及接口变更，执行 `colcon build --symlink-install`。
4. 安装并启用 `video-input.service`，确认稳定话题有帧后再启用 `stereo-depth.service`。两者均设置了相机服务依赖和失败重启。
5. 用 `ros2 topic hz`、`ros2 topic echo` 和 `curl http://127.0.0.1:8091/health` 验证；再用 0.5/1/2/3 m 标定板检查误差。

在没有左右目 ROS2 源话题和标定文件前，应保持 `stereo-depth.service` 停止，避免产生无效深度并占用有限算力。

## 5. 当前待补输入

```yaml
video_input:
  ros__parameters:
    source_left_image_topic: "<camera-driver-left-topic>"
    source_right_image_topic: "<camera-driver-right-topic>"
    source_left_camera_info_topic: "<camera-driver-left-info-topic>"
    source_right_camera_info_topic: "<camera-driver-right-info-topic>"
```

已知双目物理基线为 70 mm（`baseline_m: 0.07`，来自 CZY1D5068-V1 模组规格）。同时仍需要双目标定文件（`K_left/K_right`、`D_left/D_right`、`R`、`T` 或 `Q`）；焦距应以内参标定值为准。在这些输入确定前，程序只能通过 `simulate_input` 做软件联调，不能用于真实 SLAM 建图。

## 6. 标定板参数

当前实物棋盘格标定板每格边长为 20 mm，OpenCV 标定使用内角点数量，按照片确认默认参数为：

```yaml
checkerboard_cols: 7
checkerboard_rows: 10
square_size_m: 0.02
```

标定时双目摄像头必须固定，移动棋盘格采集同步左右图。若双目支架、镜头角度、焦距或相机安装位置发生变化，需要重新采集并生成新的双目标定文件。
