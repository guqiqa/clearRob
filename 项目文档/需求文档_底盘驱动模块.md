## 1. 模块定位

`chassis_driver` 是机器人与 OID FOC 无刷电机之间的 ROS2 桥接节点。控制逻辑运行在编译后的 C++ 核心（`chassis_core` pybind11 模块）中，完整保留同事实车调试的转向模型、原地旋转、航向保持、换向保持、档位和轮速环；Python 壳负责全部 ROS2 与硬件 I/O。

```
遥控器/App/自主导航 → /chassis/intent 或 /cmd_vel
        │
        ▼
chassis_driver (Python 壳)
  ├─ 意图仲裁 (estop > intent > cmd_vel > failsafe)
  ├─ IMU yaw 积分（订阅 /imu/data）
  ├─ CAN 调度（心跳/查询/控制周期/读线程）
  └─ ChassisCore.tick() ──→ 电流指令 ──→ can0 ──→ 电机 ×4
```

## 2. 硬件接口

### 2.1 CAN 总线

| 参数 | 值 |
|------|------|
| 接口 | `can0` (SocketCAN) |
| 波特率 | 500 Kbps |
| 帧类型 | 标准数据帧 (11-bit ID) |
| Python 库 | `python-can`（壳独占，C++ 核心无 I/O） |

### 2.2 电机 CAN ID

| CAN ID | 电机 | 功能 |
|:---:|------|------|
| `001` | 左后轮 | 行走驱动 |
| `002` | 左前轮 | 行走驱动 |
| `003` | 右后轮 | 行走驱动 |
| `004` | 右前轮 | 行走驱动 |
| `005` | 刀盘 | 切割/清扫 (二期) |

### 2.3 CAN 帧格式（OID FOC 协议，多字节大端）

**电流控制帧 (DLC=3):**
```
DATA[0] = 0x01          # 电流控制模式
DATA[1:3] = int16       # 电流值 (10mA/unit), 正=正转, 负=反转
```

**心跳帧 (DLC=1):** `DATA[0] = 0x00`

**查询帧 (DLC=2):** `DATA[0] = 0x0F, DATA[1] = 0x01`（查询转速 erpm）

**查询响应帧 (DLC=6):** `DATA[0]=0x0F, DATA[1]=0x01, DATA[2:6]=int32 erpm`（**大端**）

### 2.4 里程计参数（实测标定）

| 参数 | 值 |
|------|------|
| 磁极对数 `pole_pairs` | 10 |
| 减速比 `gear_ratio` | 5.2:1 |
| 轮半径 `wheel_radius` | 0.10 m |
| 轮距 `track_width` | 0.45 m |
| 电机方向 `motor_dirs` | [1, 1, -1, -1]（FL,RL,FR,RR，右侧反装） |

## 3. 架构（C++ 核心 + Python 壳）

### 3.1 控制逻辑 → C++ 核心（chassis_core）

同事实车验证的完整控制逻辑，pybind11 编译为 `.so`，逐字节保留：

| 逻辑 | 说明 |
|------|------|
| 转向模型 | skid-steer + 内轮约束（turn_inner_ratio=-0.20）+ 弧线过渡（700ms） |
| 原地旋转 | throttle=0+转向 → 左右轮反相 5.00A 大电流原地转 |
| 航向保持 | IMU yaw PID（Kp=1.2/Kd=0.2）直线闭环纠偏 |
| 换向保持 | 前后换向先等轮停（<5rpm 或 1.5s）再反转 |
| 档位 | LOW/MID/HIGH（70/120/140 rpm） |
| 轮速环 | current 模式：启动斜坡（55→70mA）+ 软件 PI（Kp=0.6/Ki=0.05/FF=24）+ 堵转/超速/丢反馈安全锁 |

### 3.2 I/O → Python 壳

| 职责 | 实现 |
|------|------|
| 订阅 | `/chassis/intent`（JSON）、`/cmd_vel`（兼容）、`/imu/data` |
| 发布 | `/odom`、`/chassis/status`、tf |
| 仲裁 | estop > intent 有效 > cmd_vel 有效 > failsafe |
| CAN 调度 | 心跳 200ms、查询 50ms 轮询、控制 50ms、读线程收转速 |
| IMU | 订阅 /imu/data 提取 gyro_z，3s 静校准后积分 yaw |
| 里程计 | 差速模型 + 0.85 IMU yaw 融合（与同事 Odometry 一致） |

### 3.3 意图接口（/chassis/intent）

主控制接口，任意操控源统一入口：

```json
{"throttle": 0.6, "steering": -0.3, "gear": "MID", "mower": 0, "estop": 0}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| throttle | float -1..1 | 油门（连续比例；RC 离散 ±1） |
| steering | float -1..1 | 转向 |
| gear | str | "LOW" / "MID" / "HIGH" |
| mower | 0/1 | 刀盘（二期） |
| estop | 0/1 | 急停（优先于一切） |

**仲裁优先级**（Python 壳实现）：
1. `intent.estop=1` → failsafe（硬停）
2. intent 300ms 内有效 → 用 intent
3. cmd_vel 500ms 内有效 → 转成 intent（`throttle=v/max_v, steering=w/max_w`）
4. 无任何输入 → failsafe

## 4. ROS2 接口

### 4.1 Node 信息

| 项目 | 内容 |
|------|------|
| ROS2 Node | `chassis_driver` |
| 语言 | Python 3.10+（壳）+ C++17（chassis_core .so） |
| 依赖 | `chassis_core`, `python-can`, `rclpy`, `geometry_msgs`, `nav_msgs`, `std_msgs`, `tf2_ros` |

### 4.2 订阅

| Topic | 消息类型 | QoS | 说明 |
|-------|---------|-----|------|
| `/chassis/intent` | `std_msgs/String` | 10 | 意图控制（JSON），主接口 |
| `/cmd_vel` | `geometry_msgs/Twist` | KeepLast(1) | 兼容接口（自主导航等） |
| `/imu/data` | `sensor_msgs/Imu` | 10 | 航向积分与里程计融合 |

### 4.3 发布

| Topic | 消息类型 | 频率 | 说明 |
|-------|---------|------|------|
| `/odom` | `nav_msgs/Odometry` | 50 Hz | 里程计（差速 + IMU 融合） |
| `/chassis/status` | `Float32MultiArray` | 50 Hz | [FL,RL,FR,RR rpm, yaw, rate, estop, ...] |
| `tf` (odom→base_link) | `tf2_msgs/TFMessage` | 50 Hz | 里程计 TF |

## 5. 控制周期与 CAN 调度

| 周期 | 动作 |
|------|------|
| 200ms | 心跳帧 0x00 → 4 电机 |
| 50ms | 转速查询轮询（1 电机/次，4 电机全查 200ms） |
| 50ms | 控制 tick：仲裁 → 组装反馈 → `ChassisCore.tick()` → 发电流 |
| 阻塞线程 | CAN 读：解析转速响应 → 更新 `_measured_rpm` + `_generation[cid]++` |

**关键**：每次收到新转速响应必须递增该轮的 `generation` 计数器——C++ 核心用它判断"新反馈"，驱动启动确认/堵转检测（`feedback_generation` 门控）。

## 6. 故障处理

| 故障 | 检测 | 响应 |
|------|------|------|
| CAN 无法打开 | `can0` 不存在 | 日志报错 → 模拟模式 |
| 电机超速 | `measured > 120rpm` | C++ 安全锁 → 停机，需 throttle 回中解除 |
| 启动超时 | 7s 内轮未转 | C++ 安全锁 → 停机 |
| 转速反馈丢失 | >1s 无响应 | C++ 安全锁 → 停机 |
| 输入超时 | intent/cmd_vel 无新消息 | failsafe → 电流清零 |
| 急停 | intent.estop / 遥控 SWB | failsafe → 电流清零 |

## 7. 配置参数

见 `phase1_params.yaml` 的 `chassis_core:` 段（90+ 项），完整对照表见 `需求文档_底盘核心架构.md` 第 5 节。

关键参数：
```yaml
chassis_driver:
  ros__parameters:
    can_interface: "can0"
    max_velocity: 0.5          # cmd_vel 兼容映射
    intent_timeout_ms: 300
    cmd_vel_timeout_ms: 500
    chassis_core:
      pole_pairs: 10
      gear_ratio: 5.2
      wheel_radius: 0.10
      track_width: 0.45
      motor_dirs: [1, 1, -1, -1]
      run_rpm: 100
      wheel_control_mode: "current"
      wheel_speed_kp: 0.60
      # ... (90+ 项, 见核心架构文档)
```
