## 1. 模块定位与职责边界

### 1.1 定位

`lidar_perception` 是系统的 3D 几何感知前端，承担三个核心职责：
1. **点云预处理**：接收 LiDAR 原始扫描 → 滤波/去畸变/聚类
2. **障碍物检测**：从点云中提取障碍物（位置、尺寸、距离），供融合模块与路径规划模块使用
3. **急停判断**：检测到极近距离障碍物（< 0.3m）时通过硬直达通道紧急停车

本模块不负责视觉-LiDAR 融合（由 fusion_engine 负责），不负责 SLAM 定位（由 localization_engine 负责）。

### 1.2 职责边界

| 属于本模块 | 不属于本模块 |
|-----------|-------------|
| 点云滤波（体素/统计/半径滤波） | SLAM 建图（localization_engine 负责） |
| 点云去畸变（运动补偿） | 视觉-LiDAR 融合（fusion_engine 负责） |
| 基于点云的障碍物分割与聚类 | 障碍物的语义分类（fusion_engine 负责） |
| 极近距离急停硬直达 | 避障决策（fusion_engine 负责） |

## 2. ROS2 接口规范

### 2.1 Node 信息

| 项目 | 内容 |
|------|------|
| ROS2 Node | `lidar_perception` |
| 语言 | C++17（点云处理计算密集 + PCL 库） |
| 生命周期 | ROS2 Managed Lifecycle |

### 2.2 订阅

| Topic | 消息类型 | QoS | 说明 |
|-------|---------|-----|------|
| `sensor/lidar/scan_raw` | `sensor_msgs/msg/LaserScan` 或 `sensor_msgs/msg/PointCloud2` | Sensor Data, KeepLast(5) | LiDAR 原始扫描（取决于 LiDAR 型号） |
| `master/task/mode` | `cleaning_robot_interfaces/msg/TaskMode` | Sensor Data, KeepLast(1) | 模式切换（调整扫描策略） |

### 2.3 发布

| Topic | 消息类型 | 频率 | 说明 |
|-------|---------|------|------|
| `lidar/scan/pointcloud` | `sensor_msgs/msg/PointCloud2` | 与 LiDAR 帧率同步（10~20Hz） | 预处理后点云 → localization_engine, fusion_engine |
| `lidar/obstacle/list` | `cleaning_robot_interfaces/msg/ObstacleList` | 与点云帧率同步 | 障碍物列表 + 3D 位置 → path_planner, fusion_engine |
| `lidar/cmd/estop` | `cleaning_robot_interfaces/msg/MotionCommand` | 事件驱动（急停条件触发） | 硬直达急停 → motion_controller |
| `lidar/status` | `cleaning_robot_interfaces/msg/VisionStatus` | 1Hz | 模块运行状态 |
| `system/heartbeat/lidar_perception` | `cleaning_robot_interfaces/msg/Heartbeat` | 1Hz | 心跳 |

### 2.4 Service

| Service | 类型 | 说明 |
|---------|------|------|
| `lidar/get_status` | `cleaning_robot_interfaces/srv/GetStatus` | 查询 LiDAR 状态 |
| `lidar/set_scan_freq` | `cleaning_robot_interfaces/srv/SetScanFreq` | 设置扫描频率（5~20Hz） |

## 3. 功能需求详述

### 3.1 点云预处理

**输入：** `sensor/lidar/scan_raw`（原始扫描数据）

**预处理流程（每帧执行）：**

| 步骤 | 算法 | 参数 | 说明 |
|------|------|------|------|
| 1. 格式转换 | LaserScan → PointCloud2（如需要） | — | 2D LiDAR 转 3D 点云（z=0 平面） |
| 2. 去畸变 | 里程计/IMU 运动补偿 | 需订阅 odom 数据（通过参数配置） | 机器人运动中扫描产生的点云畸变修正 |
| 3. 下采样 | VoxelGrid 体素滤波 | 体素大小: 0.05m (3D) 或 0.03m (2D) | 降低点数，提升后续处理速度 |
| 4. 离群点去除 | StatisticalOutlierRemoval | mean_k=20, std_dev_mul=2.0 | 去除噪声飞点 |
| 5. 地面分割 | RANSAC 平面拟合 | 平面阈值 0.05m，最大迭代 100 | 分离地面点与非地面点（障碍物候选） |
| 6. 范围裁剪 | PassThrough 滤波 | z: [0.1m, 3m], 半径: [0.3m, 30m] | 去除自身遮挡和过远点 |

**输出：** `lidar/scan/pointcloud`（预处理后点云，仅非地面点）

**性能要求：** 预处理延迟 ≤ 10ms（单帧 10 万点输入）

### 3.2 障碍物检测与聚类

**输入：** 预处理后的非地面点云

**处理流程：**

| 步骤 | 算法 | 参数 | 说明 |
|------|------|------|------|
| 1. 欧式聚类 | Euclidean Cluster Extraction | 聚类距离 0.1m，最小点数 10，最大点数 5000 | 将空间距离近的点聚为一个障碍物 |
| 2. 包围盒 | L-shape fitting 或 Axis-aligned BBox | — | 计算每个聚类的 3D 最小包围盒 |
| 3. 尺寸分类 | 基于包围盒对角线长度 | small<0.1m, med 0.1~0.5m, large>0.5m | 障碍物分级 |
| 4. 跟踪关联 | 基于欧式距离 + 尺寸相似度的匈牙利匹配 | max_association_dist=0.5m | 跨帧关联，分配 obstacle_id |

**输出：** `lidar/obstacle/list`（`ObstacleList.msg`，每个障碍物含：obstacle_id、position_3d、dimensions、distance、velocity、classification）

**性能要求：** 聚类+检测延迟 ≤ 15ms

### 3.3 模式感知扫描策略

根据 `master/task/mode` 调整点云处理参数：

| 模式 | 扫描频率 | 关注范围 | 地面分割 | 说明 |
|------|---------|----------|----------|------|
| CRUISE | 10Hz | 30m | 是 | 正常巡逻，全范围障碍物检测 |
| CLEAN | 20Hz | 10m | 否（清扫区域地面已知为平面） | 低速清扫，高频近场检测（防止碰撞清扫区域边缘） |
| RETURN | 10Hz | 30m | 是 | 同 CRUISE |

### 3.4 急停判断（硬直达）

**触发条件（任一满足即触发）：**

| 条件 | 阈值 | 说明 |
|------|------|------|
| 障碍物距离 < 最小安全距离 | < 0.3m（CRUISE/CLEAN）/ < 0.5m（RETURN） | 根据当前模式选择阈值 |
| 障碍物尺寸 large + 距离 < 1m + 障碍物位于机器人正前方 ± 30° | — | 大型物体正前方，提前急停 |
| 点云帧间突变 | 当前帧有效点数 < 上一帧 × 0.3（传感器遮挡或故障） | 防止盲区碰撞 |

**急停发布：** `lidar/cmd/estop(MotionCommand(estop=true))`

**急停解除：** 连续 5 帧无急停条件 → `lidar/cmd/estop(MotionCommand(estop=false))`

**防抖机制：** 急停触发需连续 2 帧满足条件（防止单帧噪声误触）；急停解除需连续 5 帧安全（共 250~500ms，防止抖动）。

## 4. 配置参数（ROS2 Parameter YAML）

```yaml
lidar_perception:
  ros__parameters:
    # LiDAR 硬件
    lidar_model: "Velodyne_VLP16"        # 或 "RoboSense_RS16" 等
    scan_freq: 10.0                      # 默认扫描频率 Hz
    horizontal_fov_deg: 360.0            # 水平视场角
    vertical_fov_deg: 30.0               # 垂直视场角
    
    # 预处理
    voxel_leaf_size: 0.05                # 体素滤波格大小 (m)
    sor_mean_k: 20                       # 统计滤波邻居数
    sor_std_dev_mul: 2.0                 # 统计滤波标准差倍数
    ground_ransac_threshold: 0.05        # RANSAC 地面平面阈值 (m)
    height_filter_min: 0.1               # 高度过滤最小值 (m)（排除自身）
    height_filter_max: 3.0               # 高度过滤最大值 (m)
    radius_filter_min: 0.3               # 半径过滤最小值 (m)（排除自身遮挡）
    radius_filter_max: 30.0              # 半径过滤最大值 (m)
    
    # 障碍物聚类
    cluster_tolerance: 0.1               # 欧式聚类距离阈值 (m)
    cluster_min_points: 10               # 最小聚类点数
    cluster_max_points: 5000             # 最大聚类点数
    assoc_max_distance: 0.5              # 跨帧跟踪最大关联距离 (m)
    
    # 急停
    estop_min_distance_cruise: 0.3       # 巡航模式最小安全距离 (m)
    estop_min_distance_clean: 0.3        # 清扫模式最小安全距离 (m)
    estop_min_distance_return: 0.5       # 返航模式最小安全距离 (m)
    estop_large_obstacle_threshold: 1.0  # 大型障碍物急停触发距离 (m)
    estop_large_obstacle_angle: 30.0     # 大型障碍物前方角度 (°)
    estop_trigger_frames: 2              # 急停触发需连续帧数
    estop_release_frames: 5              # 急停解除需连续帧数
    estop_pointcloud_ratio_min: 0.3      # 点云点数突变阈值
    
    # 性能
    max_preprocessing_latency_ms: 10.0   # 预处理最大延迟
    max_clustering_latency_ms: 15.0      # 聚类最大延迟
```

## 5. 异常处理

| 故障场景 | 检测方式 | 响应行为 |
|----------|----------|----------|
| LiDAR 硬件故障 | `sensor/lidar/scan_raw` 超时 > 2s | 发布 status=2（故障），停止发布点云和障碍物，master_controller 进入安全模式 |
| 点云大量噪声 | 连续 10 帧 StatisticalOutlierRemoval 滤除 > 50% 点 | 发布 status=1（降级），调大滤波参数 |
| 扫描频率不稳定 | 实际帧率波动 > ±20% 目标频率 | 发布 WARN，但不影响处理 |
| 预处理延迟超标 | 单帧处理 > 50ms 持续 30s | 降低下采样精度（增大体素格至 0.1m） |

## 6. 开发里程碑

| 阶段 | 内容 | 交付物 |
|------|------|--------|
| M1: 基础点云 | 格式转换 + VoxelGrid + PassThrough | 预处理点云流 |
| M2: 聚类检测 | 欧式聚类 + 包围盒 + 尺寸分类 | 障碍物列表输出 |
| M3: 急停 | 三级急停条件 + 硬直达 Topic | ESTOP 通路 |
| M4: 模式感知 | CRUISE/CLEAN/RETURN 自适应扫描 | 模式联动 |
| M5: 集成 | 与 localization + fusion 联调 | 全链路 |
