## 1. 模块定位与职责边界

### 1.1 定位

`motion_controller` 是系统的运动执行机构，负责底盘驱动、速度闭环控制、里程计发布。接收仲裁后运动指令，转化为四驱电机的 PWM/电流指令，是九大模块中直接控制硬件的节点。

### 1.2 职责边界

| 属于本模块 | 不属于本模块 |
|-----------|-------------|
| 底盘四驱电机控制（PID 速度闭环） | 运动指令决策（master_controller 仲裁） |
| 差速转向控制 | 路径跟踪控制（path_planner 的 Pure Pursuit） |
| 里程计计算与发布 | 路径规划（path_planner 负责） |
| 急停硬件执行 | 急停判断（LiDAR + 遥控器 负责） |
| 坡道辅助（IMU 俯仰补偿） | SLAM 定位（localization_engine 负责） |
| Action Server: follow_path | — |

## 3. 功能需求详述

### 3.1 底盘驱动（差速转向）

**驱动模型：** 四驱差速底盘
- 左侧轮组 = 左前 + 左后（同速控制）
- 右侧轮组 = 右前 + 右后（同速控制）

**运动学解算（Twist → 轮速）：**
```
v_left  = linear_velocity - angular_velocity * (wheel_base / 2)
v_right = linear_velocity + angular_velocity * (wheel_base / 2)
```

**底盘参数：**
- 轮距 (wheel_base): 0.6m（可通过参数配置）
- 轮径: 0.2m
- 减速比: 1:20
- 最大轮转速: 120 RPM（对应线速度约 1.5 m/s）

### 3.2 速度闭环控制

**控制回路：**
```
目标速度 (v_target) ──→ [PID控制器] ──→ PWM/电流输出 → 无刷电机
                                              │
                        实测速度 (v_actual) ←── 编码器
```

**PID 参数（可运行时通过 ros2 param 微调）：**
- Kp = 0.5, Ki = 0.1, Kd = 0.05
- 控制频率: 200Hz
- 积分饱和限制: ±30% 输出
- 死区: |目标速度| < 0.01 m/s 时输出 0（防止静态抖动）

**性能要求：**
- 速度跟踪稳态误差 ≤ 5%
- 速度阶跃响应上升时间 ≤ 200ms
- 超调量 ≤ 10%

### 3.3 运动指令处理

**正常运动指令（来自 `master/cmd/motion`）：**
1. 检查 estop 标志：若 `MotionCommand.estop == true` → 立即切断所有电机输出，不等待 PID 自然减速
2. 限幅：linear_velocity 限制在 [-max_linear_velocity, +max_linear_velocity]，angular_velocity 限制在 [-max_angular_velocity, +max_angular_velocity]
3. 前馈 + 反馈控制：线速度采用 PI 控制（前馈 PWM + 积分补偿），角速度采用 PID
4. 差速解算后输出到四轮

**急停指令（来自 `motion/cmd/estop` 硬直达通道）：**
1. 优先级最高：收到 estop=true → 立即硬件断电（MOS 管关断），不经过 PID 回路
2. estop=false → 恢复供电，等待下一个 `master/cmd/motion` 指令
3. 急停触发后，发布 `motion/status/fault(fault_code=6, fault_text="ESTOP_ACTIVATED")`

### 3.4 里程计计算与发布

**输入：** 四轮编码器脉冲 + IMU 角速度

**计算流程：**
1. 编码器脉冲 → 轮位移：`Δs = 2πR × (pulses / pulses_per_rev) / gear_ratio`
2. 差速里程计：`Δx = (Δs_left + Δs_right) / 2 × cos(θ)`
   `Δy = (Δs_left + Δs_right) / 2 × sin(θ)`
   `Δθ = (Δs_right - Δs_left) / wheel_base`
3. IMU 融合：角速度与编码器角速度互补滤波（系数 α=0.95 编码器, 1-α=0.05 IMU）
4. 发布 `nav_msgs/msg/Odometry`（100Hz）：
   - `pose.pose`：累积位姿（Map 坐标系原点 = 上电位置）
   - `twist.twist`：瞬时速度（直接用编码器测量值）
   - `pose.covariance`：协方差矩阵（根据编码器分辨率 + IMU 噪声推算）

### 3.5 坡道辅助

**触发条件：** IMU 俯仰角 |pitch| > 5°

**处理：**
1. 上坡：增加电机输出力矩（PWM 提升比例 = 1 + 0.05 × |pitch_deg|），补偿重力分量
2. 下坡：限制线速度不超限（通过轻制动实现，占空比 ≤ 5% 反向），防止溜车
3. 坡度 > 15°：发布 WARN 告警，不建议通过，由 master_controller 决策
4. 坡度 > 20°：发布 FAULT（fault_code=7），自动急停

### 3.6 电机故障检测

| 故障码 | 条件 | 响应 |
|--------|------|------|
| 1（过流） | 电机电流 > 额定 × 1.5 持续 > 1s | 切断该路电机输出，发布 FaultStatus(requires_reset=true) |
| 2（过热） | 电机温度 > 80°C | 降低最大速度至 50%，发布 WARN |
| 2（过热严重） | 电机温度 > 100°C | 切断所有电机输出，发布 FaultStatus(requires_reset=true) |
| 3（编码器失步） | 编码器读数与 IMU 推算偏差 > 20% 持续 > 3s | 发布 FaultStatus，仍可运行但里程计不可靠 |
| 4（通信超时） | `master/cmd/motion` 超时 > 500ms | 自动降速至停止（线性减速 1.0 m/s² 至 0） |
| 5（驱动器故障） | 驱动器返回错误码 | 发布 FaultStatus(requires_reset=true) |
| 6（急停触发） | `motion/cmd/estop(estop=true)` | 硬件断电 |
| 7（超坡度） | 俯仰角 > 20° | 自动急停，发布 FaultStatus |

## 4. Action Server: follow_path

### 4.1 Goal（接收）

| 字段 | 类型 | 说明 |
|------|------|------|
| waypoints | geometry_msgs/PoseStamped[] | 目标路径点序列 |
| target_velocity | float32 | 目标线速度 m/s |

### 4.2 Feedback（发送）

| 字段 | 类型 | 说明 |
|------|------|------|
| current_waypoint_idx | uint32 | 当前目标路径点索引 |
| lateral_deviation | float32 | 当前横向偏差 (m) |
| path_progress | float32 | 路径完成进度 0.0~1.0 |

### 4.3 Result（返回）

| 字段 | 类型 | 说明 |
|------|------|------|
| success | bool | 是否成功完成全程 |
| completed_waypoints | uint32 | 完成路径点数 |
| deviation_max | float32 | 最大横向偏差 (m) |

### 4.4 执行逻辑

内部不执行路径跟踪控制，而是将 waypoints 透传给 path_planner（通过内部 Topic），由 path_planner 的 Pure Pursuit 控制器生成 maneuver。follow_path Action 仅在 path_planner 输出 COMPLETED 或 BLOCKED 时返回 Result。

实际上 motion_controller 的 follow_path 仅充当"路径执行监督"角色：监控 path_planner 的跟踪进度，在到达最终目标或偏差过大时终止 Action。

## 5. 配置参数（ROS2 Parameter YAML）

```yaml
motion_controller:
  ros__parameters:
    # 底盘参数
    wheel_base: 0.6                      # 轮距 (m)
    wheel_radius: 0.1                    # 轮径 (m)
    gear_ratio: 20.0                     # 减速比
    pulses_per_rev: 2048                 # 编码器脉冲数/圈
    
    # 速度限制
    max_linear_velocity: 1.5             # 最大线速度 m/s
    max_angular_velocity: 2.0            # 最大角速度 rad/s
    max_linear_accel: 1.0                # 最大线加速度 m/s²
    max_angular_accel: 2.0               # 最大角加速度 rad/s²
    
    # PID
    pid_kp: 0.5
    pid_ki: 0.1
    pid_kd: 0.05
    pid_integral_max: 0.3
    dead_zone_ms: 0.01                   # 死区速度 m/s
    control_rate: 200.0                  # PID 控制频率 Hz
    
    # 里程计
    odom_publish_rate: 100.0             # 里程计发布频率 Hz
    imu_fusion_alpha: 0.95               # 编码器互补滤波系数
    
    # 保护
    current_overload_ratio: 1.5          # 过流倍数阈值
    current_overload_timeout_s: 1.0      # 过流持续超时
    temperature_warn_c: 80.0             # 电机过热告警温度
    temperature_cutoff_c: 100.0          # 电机过热切断温度
    master_cmd_timeout_ms: 500           # 运动指令超时 (ms)
    
    # 坡道
    slope_assist_min_deg: 5.0            # 坡道辅助触发角度
    slope_warn_deg: 15.0                 # 坡度告警角度
    slope_max_deg: 20.0                  # 最大允许坡度
```

## 6. 异常处理

| 故障场景 | 检测方式 | 响应行为 |
|----------|----------|----------|
| 运动指令超时 | master_cmd_timeout_ms 无新指令 | 线性减速至零（1.0 m/s²），不发布 FaultStatus |
| 编码器断线 | 脉冲数不变但 PWM>0（持续 1s） | 发布 FaultStatus(fault_code=3)，通知定位模块 |
| 电机堵转 | 占空比 > 50% 但速度 < 0.05 m/s 持续 3s | 发布 FaultStatus(fault_code=5)，切断该电机 |
| 急停硬直达 | estop=true | 硬件断电，PID 积分清零 |

|------|------|--------|
| M1: 底盘驱动 | 四驱差速控制 + 运动学解算 | 底盘可遥控前进/后退/转向 |
| M2: 速度闭环 | PID 闭环 + 编码器反馈 | 速度跟踪精度 < 5% |
