# 需求文档 — 消息接口规范（cleaning_robot_interfaces）

> 来源：智能环卫机器人控制系统需求文档 V2.4  
> 文档代号：需求文档_消息接口规范 V1.1  
> 更新：2026-06-30

---

## 1. 定位

`cleaning_robot_interfaces` 是独立 ROS2 Package，定义所有模块共享的自定义消息（`.msg`）、服务（`.srv`）和动作（`.action`）。本包不含任何可执行代码，仅为类型定义，所有模块通过 `#include` 或 `from cleaning_robot_interfaces` 引用。

- Message：模块间 Topic 通信的数据载体
- Service：请求/响应模式的配置与查询接口
- Action：长时任务接口（带进度反馈与取消）

## 2. 消息定义（.msg）

### 2.1 Detection.msg

```ros2
# 单个检测目标
# 坐标系统：xmin,ymin,xmax,ymax 为像素坐标（相对于原始相机图像分辨率，左上角为原点）
# 坐标由 vision_detector 直接从 YOLO 推理输出取整后填入，fusion_engine 负责结合相机内参完成 2D→3D 投影
string   class_name          # 类别名称（recyclable/kitchen_waste/hazardous/other_waste/green_waste/road_obstacle/pedestrian_pet/stain）
float32  confidence          # 置信度 0.0~1.0
uint16   class_id            # 类别 ID 0~7
int32    xmin                # 边界框左上角 x 像素坐标（0-indexed）
int32    ymin                # 边界框左上角 y 像素坐标（0-indexed）
int32    xmax                # 边界框右下角 x 像素坐标（exclusive）
int32    ymax                # 边界框右下角 y 像素坐标（exclusive）
```

### 2.2 DetectionArray.msg

```ros2
# 一帧检测结果（vision_detector 发布至 vision/detect/list）
# ⚠️ 关键契约：Header.stamp 必须设置为摄像头原始图像的时间戳
#   （即 sensor_msgs/Image.header.stamp），严禁使用节点发布时的系统当前时间。
#   时间戳偏差会导致 fusion_engine 在做 2D 检测框与 LiDAR 点云空间关联时出现坐标漂移。
std_msgs/Header  header      # stamp = 相机图像时间戳；frame_id = camera 光心坐标系
Detection[]      detections  # 检测目标数组，可为空（无检测结果）
uint32           frame_seq   # 帧序号，单调递增，溢出归零
float32          inference_ms # 本次推理耗时（ms），不含通信开销
```

### 2.3 TaskMode.msg

```ros2
# 由 master_controller 发布，通知各模块切换运行模式
std_msgs/Header  header
uint8            mode        # 0=CRUISE（巡逻巡航） 1=CLEAN（定点清扫） 2=RETURN（返航充电）
string           mode_name   # "CRUISE" / "CLEAN" / "RETURN"
```

### 2.4 TaskArea.msg

```ros2
# 清扫区域任务，由 master_controller → path_planner
std_msgs/Header  header
string           area_id             # 区域唯一标识（UUID）
geometry_msgs/Polygon  boundary      # 区域多边形边界（GPS 或 Map 坐标系）
uint32           cleaning_passes     # 覆盖清扫次数（默认 1）
float32          overlap_ratio       # 路径重叠率 0.0~0.3（默认 0.1）
```

### 2.5 CleanStrategy.msg

```ros2
# 清扫策略指令，由 master_controller → cleaning_actuator
std_msgs/Header  header
uint8            strategy            # 0=COVER（覆盖式全场清扫）1=SPOT（定点密集清扫）2=TRACK（追踪式跟随垃圾路径）3=IDLE（待命，停止清扫执行机构）
float32          suction_power       # 吸力 0.0~1.0（0=最低，1=最高）
float32          water_amount        # 洒水量 0.0~1.0（0=无洒水，1=最大）
float32          brush_speed         # 刷盘转速 0.0~1.0（0=停止，1=最高速）
```

### 2.6 MotionCommand.msg

```ros2
# 仲裁后统一运动指令，由 master_controller → motion_controller
std_msgs/Header  header
float32          linear_velocity     # 线速度 m/s（前进为正，后退为负）
float32          angular_velocity    # 角速度 rad/s（逆时针为正，顺时针为负）
bool             estop               # 急停标志 true=立即停止所有电机
```

### 2.7 UnifiedCommand.msg

```ros2
# 归一化控制指令，由 control_gateway → master_controller
std_msgs/Header  header
uint8            command             # 指令码 0~9（见指令码表）
string           command_name        # "START"/"PAUSE"/"RESUME"/"STOP"/"RETURN"/"MANUAL"/"SET_AREA"/"SET_MODE"/"ESTOP"
uint8            source              # 来源 0=遥控器 1=App 2=语音
float32[]        params              # 指令附参 [0]=区域ID, [1]=模式值 等，按指令码解释
```

### 2.8 Path.msg

```ros2
# 目标路径点序列，由 path_planner → master_controller
std_msgs/Header  header
geometry_msgs/PoseStamped[]  waypoints   # 路径点序列（全局坐标系）
float32          total_length           # 路径总长度 (m)
uint32           sequence               # 路径序号（每次规划递增，供 master 判断是否为新路径）
```

### 2.9 PlannerState.msg

```ros2
# 路径规划状态，由 path_planner → master_controller
std_msgs/Header  header
uint8            state               # 0=IDLE（无任务） 1=PLANNING（计算中） 2=READY（路径就绪） 3=EXECUTING（路径跟踪中） 4=REPLANNING（局部重规划中） 5=BLOCKED（无法规划/路径阻塞） 6=COMPLETED（到达目标点）
string           state_text          # 状态文本描述
```

### 2.10 ObstacleItem.msg

```ros2
# 单个障碍物信息，由 lidar_perception 发布
std_msgs/Header  header
uint32           obstacle_id         # 障碍物唯一 ID（跟踪用，同一障碍物跨帧不变）
geometry_msgs/Point  position       # 障碍物中心 3D 位置（LiDAR 坐标系）
geometry_msgs/Vector3  dimensions  # 障碍物尺寸 x=长 y=宽 z=高 (m)
float32          distance            # 距机器人距离 (m)
float32          velocity            # 相对速度 (m/s)，0=静态
uint8            classification     # 0=未知 1=小件（<0.1m） 2=中件（0.1~0.5m） 3=大件（>0.5m）
```

### 2.11 ObstacleList.msg

```ros2
# 障碍物列表，由 lidar_perception 发布
std_msgs/Header  header
ObstacleItem[]   obstacles           # 当前帧检测到的所有障碍物
```

### 2.12 Fusion3DTarget.msg

```ros2
# 后融合 3D 目标告警，由 fusion_engine → master_controller
std_msgs/Header  header
string           target_class        # 目标类别（来自视觉检测）
float32          confidence          # 融合置信度 0.0~1.0
geometry_msgs/Point  position_3d    # 3D 位置（Map 坐标系）
geometry_msgs/Vector3  dimensions  # 目标尺寸 (m)
uint8            alert_level         # 0=INFO 1=WARN（需关注但非紧急） 2=CRITICAL（需立即调度干预，如行人突然靠近）
string           alert_reason        # 告警原因
```

### 2.13 FusionDecision.msg

```ros2
# 避障决策，由 fusion_engine → path_planner
std_msgs/Header  header
uint8            action              # 0=PASS（可通行） 1=DETOUR（绕行） 2=WAIT（等待障碍物离开） 3=SLOW（减速通过）
uint32           target_id           # 关联的障碍物 ID（对应 ObstacleItem.obstacle_id）
float32          detour_offset       # 绕行偏移量 (m)，仅在 action=DETOUR 时有效
float32          wait_duration       # 等待时长 (s)，仅在 action=WAIT 时有效
float32          slow_ratio          # 减速比例 0.0~1.0，仅在 action=SLOW 时有效（0.5=降至当前速度 50%）
```

### 2.14 MotorStatus.msg

```ros2
# 电机状态，由 motion_controller 发布
std_msgs/Header  header
float32          motor_left_front    # 左前轮转速 RPM
float32          motor_right_front   # 右前轮转速 RPM
float32          motor_left_rear     # 左后轮转速 RPM
float32          motor_right_rear    # 右后轮转速 RPM
float32          motor_current       # 总电流 (A)
float32          motor_voltage       # 电压 (V)
float32          temperature         # 电机温度 (°C)
```

### 2.15 FaultStatus.msg

```ros2
# 故障状态，由 motion_controller 发布
std_msgs/Header  header
uint8            fault_code          # 0=无故障 1=电机过流 2=电机过热 3=编码器失步 4=通信超时 5=驱动器故障 6=急停触发
string           fault_text          # 故障描述
bool             requires_reset      # 是否需要外部复位才能恢复
```

### 2.16 CleaningProgress.msg

```ros2
# 清扫进度，由 cleaning_actuator 发布
std_msgs/Header  header
string           area_id             # 对应 TaskArea.area_id
float32          progress            # 进度 0.0~1.0（0=未开始，1=完成）
float32          cleaned_area_m2     # 已清扫面积 (m²)
float32          estimated_remaining_s # 预计剩余时间 (s)
```

### 2.17 CleaningStats.msg

```ros2
# 清扫统计数据，由 cleaning_actuator 发布
std_msgs/Header  header
float32          total_area_m2       # 本次任务累计清扫面积 (m²)
float32          waste_volume_l      # 预估垃圾收集量 (L)
float32          avg_cleanliness     # 平均清洁度评分
```

### 2.18 BrushStatus.msg

```ros2
# 刷盘状态，由 cleaning_actuator 发布
std_msgs/Header  header
float32          main_brush_rpm      # 主刷转速 RPM
float32          side_brush_rpm      # 边刷转速 RPM
float32          main_brush_wear     # 主刷磨损率 0.0~1.0（1.0=需更换）
float32          side_brush_wear     # 边刷磨损率 0.0~1.0
```

### 2.19 DustFull.msg

```ros2
# 尘满告警，由 cleaning_actuator 发布
std_msgs/Header  header
bool             is_full             # true=尘满
float32          dust_level          # 尘量 0.0~1.0（0=空，1=满）
float32          filter_clog_ratio   # 滤网堵塞率 0.0~1.0
```

### 2.20 VisionStatus.msg

```ros2
# 视觉模块运行状态，由 vision_detector 发布
string           active_model        # 当前加载的模型文件名
float32          avg_inference_ms    # 最近 30 帧平均推理耗时
float32          fps                 # 实际帧率
uint8            status              # 0=正常 1=降级（帧率受限但可用） 2=故障（无输出）
string           status_text         # 状态描述
```

### 2.21 Heartbeat.msg

```ros2
# 节点心跳，所有模块统一格式，1Hz 发布至 system/heartbeat/{node_name}
std_msgs/Header  header
string           node_name           # 节点名称（与 system/heartbeat/ 后段一致）
uint8            lifecycle_state     # 1=Unconfigured 2=Inactive 3=Active 4=Finalized
uint8            error_code          # 0=进程正常 1=初始化失败 2=运行时异常退出
```

### 2.22 Alert.msg

```ros2
# 系统告警，由各模块发布至 system/alert
std_msgs/Header  header
string           source_node         # 告警来源节点名
uint8            severity            # 0=INFO 1=WARN 2=ERROR 3=FATAL
string           alert_code          # 告警码（如 "E001_CAMERA_TIMEOUT"）
string           alert_text          # 告警描述
```

## 3. 服务定义（.srv）

### 3.1 SetModel.srv

```ros2
# 热切换视觉模型
string   model_path          # 请求：模型文件绝对路径（.pt/.onnx/.engine）
---
bool     success             # 是否加载成功
string   message             # 成功：模型摘要；失败：错误原因
```

### 3.2 GetStatus.srv（通用状态查询 — 各模块复用）

```ros2
# 请求参数为空
---
string   node_name           # 节点名
uint8    status              # 模块自定义状态码（每个模块定义各自的 0/1/2 语义）
string   status_text         # 状态描述
float32  uptime_s            # 节点运行时长 (s)
```

### 3.3 SetPriority.srv

```ros2
# 运行时调整控制优先级规则（仅供 control_gateway）
string   rule                # "RC_ONLY"=仅遥控器 "RC_APP"=遥控+App（默认） "ALL"=全部并行
---
bool     success
string   message
```

### 3.4 SetMaxSpeed.srv

```ros2
# 设置底盘最大速度
float32  max_linear_velocity  # 最大线速度 m/s（0.1~2.0）
float32  max_angular_velocity # 最大角速度 rad/s（0.1~3.0）
---
bool     success
string   message
```

### 3.5 GetCurrentPose.srv

```ros2
# 查询机器人当前位姿
---
geometry_msgs/PoseWithCovariance  pose   # 当前位姿 + 协方差
bool                              valid  # 位姿是否有效（定位置信度 > 阈值）
```

### 3.6 RequestMap.srv

```ros2
# 请求当前占据栅格地图
geometry_msgs/Polygon  roi            # 请求区域（空 = 返回全图）
---
nav_msgs/OccupancyGrid  map           # 占据栅格地图
bool                    success
```

### 3.7 SetScanFreq.srv

```ros2
# 设置 LiDAR 扫描频率
float32  frequency          # 扫描频率 Hz（5~20）
---
bool     success
string   message
```

## 4. 动作定义（.action）

### 4.1 NavigateToGoal.action

```ros2
# 导航至目标点（path_planner Action Server，由 master_controller 调用）
# --- Goal ---
geometry_msgs/PoseStamped  target_pose    # 目标位姿（Map 坐标系）
float32                    target_tolerance  # 到达容差 (m)，默认 0.1
float32                    timeout_s      # 超时时间 (s)，0=无超时
# --- Result ---
bool                       success        # 是否成功到达
float32                    final_distance # 最终距目标点距离 (m)
float32                    path_length    # 实际行驶路径长度 (m)
# --- Feedback ---
float32                    progress       # 进度 0.0~1.0
float32                    distance_to_goal # 当前距目标点距离 (m)
float32                    estimated_remaining_s # 预计剩余时间 (s)
```

### 4.2 FollowPath.action

```ros2
# 路径跟踪执行（motion_controller Action Server，由 master_controller 调用）
# --- Goal ---
geometry_msgs/PoseStamped[]  waypoints    # 目标路径点序列
float32                      target_velocity  # 目标线速度 (m/s)
# --- Result ---
bool                         success      # 是否成功完成全程
uint32                       completed_waypoints # 完成路径点数
float32                      deviation_max # 最大横向偏差 (m)
# --- Feedback ---
uint32                       current_waypoint_idx # 当前目标路径点索引
float32                      lateral_deviation    # 当前横向偏差 (m)
float32                      path_progress        # 路径完成进度 0.0~1.0
```

### 4.3 ExecuteCleanup.action

```ros2
# 执行清扫（cleaning_actuator Action Server，由 master_controller 调用）
# --- Goal ---
uint8            strategy            # 0=COVER 1=SPOT 2=TRACK
float32          duration_s          # 清扫持续时长 (s)，0=持续到收到取消
# --- Result ---
bool             success
float32          actual_duration     # 实际清扫时长 (s)
float32          waste_collected_l   # 垃圾收集量 (L)
float32          avg_cleanliness_before # 清扫前平均清洁度
float32          avg_cleanliness_after  # 清扫后平均清洁度
# --- Feedback ---
float32          elapsed_s           # 已执行时长 (s)
float32          cleanliness_current # 当前清洁度
float32          waste_instant_l     # 瞬时垃圾收集量
```

## 5. 命名规范汇总

| 规则 | 格式 | 示例 |
|------|------|------|
| Topic | `{module}/{action}[/{detail}]` | `vision/detect/list` |
| Service | `{module}/{verb}_{noun}` | `motion/set_max_speed` |
| Action | `{module}/{task_name}` | `planner/navigate_to_goal` |
| 心跳 | `system/heartbeat/{node_name}` | `system/heartbeat/vision_detector` |
| 系统告警 | `system/alert` | 所有模块共用 |
| 参数 | `{node_name}.ros__parameters.{name}` | `vision_detector.ros__parameters.conf_threshold` |

## 6. QoS 配置

| 通信类型 | QoS Profile | 适用场景 |
|----------|------------|----------|
| 传感器数据（图像/点云） | Sensor Data: Reliable, Volatile, KeepLast(depth=5) | 高频率、允许丢旧帧 |
| 状态数据（心跳/状态/清洁度） | Sensor Data: Reliable, Volatile, KeepLast(depth=1) | 低频、仅关心最新值 |
| 指令数据（归一化指令/运动指令/模式） | Sensor Data: Reliable, TransientLocal, KeepLast(depth=1) | 不可丢失，瞬态 |
| Service | Services: Reliable, Volatile | 请求/响应 |
| Action | Action: Reliable, TransientLocal | 长时任务 |
| 急停 | Sensor Data: Reliable, TransientLocal, KeepLast(depth=1) | 最高优先级硬直达 |
