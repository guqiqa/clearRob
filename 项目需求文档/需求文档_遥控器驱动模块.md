## 1. 模块定位

`remote_driver` 解析 SBUS 协议遥控器信号 (16 通道)，发布 ROS2 `sensor_msgs/Joy` 消息。一期中遥控器是唯一的控制输入方式。

---

## 2. 硬件接口

### 2.1 SBUS 协议

| 参数 | 值 |
|------|------|
| 协议 | SBUS (Futaba 标准) |
| 传输 | UART 100 Kbps, 8E2 (8 data bits, even parity, 2 stop bits) |
| 帧长 | 25 字节 |
| 帧率 | 7-14ms/帧 (约 70-140 Hz) |
| 设备路径 | `/dev/ttyS1` @ 115200 bps (经 MCU 转发) |

> **注意**: `/dev/ttyS1` 的实际波特率是 115200，但 SBUS 信号本身是 100Kbps。MCU 中间层做了速率转换。串口参数应为 `115200, 8N1` (MCU 端)。具体串口路径和参数待实机确认。

### 2.2 SBUS 帧格式

```
Byte 0:    0x0F (帧头)
Byte 1-22: 16 通道 × 11-bit = 176 bit = 22 bytes (小端位编码)
Byte 23:   标志位:
            bit 0 = CH17 (数字通道)
            bit 1 = CH18 (数字通道)
            bit 2 = Failsafe 激活 (1 = 失控保护)
            bit 3 = Frame lost (1 = 丢帧)
Byte 24:   0x00 (帧尾)
```

### 2.3 通道值范围

| 通道值 | 含义 |
|:---:|------|
| 172 | 最小值 (舵机 -100%) |
| 992 | 中位 (舵机 0%) |
| 1811 | 最大值 (舵机 +100%) |

### 2.4 通道映射 (厂商预设)

| 通道 | 控制 | 用途 |
|:---:|------|------|
| CH1 | 右摇杆 X | 转向 (角速度) |
| CH2 | 左摇杆 Y | 油门 (线速度) |
| CH3 | 右摇杆 Y | (备用) |
| CH4 | 左摇杆 X | (备用) |
| CH5 | SWA 开关 | START/STOP 切换 |
| CH6 | SWB 开关 | (备用) |
| CH7 | SWC 开关 | 急停 |
| CH8 | SWD 开关 | 模式切换 |

## 4. 功能需求

### 4.1 SBUS 解码

```python
def decode_sbus(data: bytes):
    """解码 SBUS 25 字节 → 16 通道值 + 标志位"""
    if len(data) != 25 or data[0] != 0x0F or data[24] != 0x00:
        return None  # 无效帧
    
    channels = [0] * 16
    # 位解码: 从 byte[1] 开始, 每隔 11-bit 取一个通道
    bit_pos = 0
    byte_idx = 1
    current_byte = data[byte_idx]
    
    for ch in range(16):
        value = 0
        bits_read = 0
        while bits_read < 11:
            if bit_pos >= 8:
                byte_idx += 1
                current_byte = data[byte_idx]
                bit_pos = 0
            bits_remaining = 11 - bits_read
            bits_in_byte = 8 - bit_pos
            n = min(bits_remaining, bits_in_byte)
            mask = (1 << n) - 1
            value |= ((current_byte >> bit_pos) & mask) << bits_read
            bit_pos += n
            bits_read += n
        channels[ch] = value
    
    flags = data[23]
    failsafe = bool(flags & 0x04)
    frame_lost = bool(flags & 0x08)
    
    return channels, failsafe, frame_lost
```

### 4.2 Joy 消息填充

```python
joy_msg = Joy()
joy_msg.header.stamp = node.get_clock().now().to_msg()
joy_msg.header.frame_id = "rc_link"

# axes: 摇杆归一化到 [-1.0, +1.0]
# 中位=992, 范围: 172-1811
def sbus_to_axis(raw):
    if raw < 992:
        return -(992 - raw) / (992 - 172)  # -1.0 .. 0
    else:
        return (raw - 992) / (1811 - 992)  # 0 .. +1.0

joy_msg.axes = [
    sbus_to_axis(channels[0]),   # CH1: 转向
    sbus_to_axis(channels[1]),   # CH2: 油门
    sbus_to_axis(channels[2]),   # CH3
    sbus_to_axis(channels[3]),   # CH4
]

# buttons: 开关通道二值化 (中位以上 = 按下)
def sbus_to_button(raw):
    return 1 if raw > 1200 else 0

joy_msg.buttons = [
    sbus_to_button(channels[4]),  # CH5: START/STOP
    sbus_to_button(channels[5]),  # CH6
    sbus_to_button(channels[6]),  # CH7: 急停
    sbus_to_button(channels[7]),  # CH8: 模式
]
```

### 4.3 失控保护

```python
if failsafe or frame_lost:
    # 立即将 axes 归零 (停止运动)
    joy_msg.axes = [0.0] * 4
    joy_msg.buttons[2] = 1  # 强制急停
    node.get_logger().error("SBUS failsafe/lost frame — emergency stop")
```

### 4.4 模拟模式

当 `simulate:=true` 时:
- 不打开 `/dev/ttyS1`
- 发布中立摇杆 + 无按钮的 Joy (即不控制)
- 日志 `[SIM] remote_driver running in simulated mode`

## 5. 配置参数

```yaml
remote_driver:
  ros__parameters:
    device: "/dev/ttyS1"
    baudrate: 115200
    frame_id: "rc_link"

    # 通道归一化
    sbus_min: 172
    sbus_center: 992
    sbus_max: 1811
    
    # 轴死区 (摇杆中位附近视为 0, 防止漂移)
    axis_deadzone: 0.05

    # 模拟
    simulate: false
```
