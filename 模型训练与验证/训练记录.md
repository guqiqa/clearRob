## 8. 结论

| 结论 | 说明 |
|------|------|
| **Mosaic 是崩溃根因** | 35k 张"全图一框"的分类图片在 Mosaic 拼图时产生矛盾梯度，关闭后 3 轮训练崩溃彻底消失 |
| **v1 仍是最优可用模型** | best.pt E52, mAP50=0.895，但 pedestrian_pet 被过度强化 |
| **v5 在健康收敛中** | E25 mAP50=0.787，cls_loss 0.50，val_cls 0.66，25 ep 无任何崩溃。训练已暂停 |
| **person cap 需调优** | cap=2 导致行人 AP 崩到 0.316；cap=3 (v5) 待评估 |
| **v5 预计 E50-70 超越 v1** | 无 Mosaic 收敛慢但稳定，类间分布预期更均衡 |
