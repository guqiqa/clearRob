## 4. 应对策略

| 风险 | 缓解措施 |
|------|----------|
| 整图框 28% 占比梯度污染 | Mosaic=0.0 已验证安全；garbage_classify 仅覆盖 4 个类 |
| road_obstacle 类内语义差异大（car + tree + cone + bin） | 策略一致（都绕行，都不清扫），内聚性高 |
| hazardous/other_waste 类间相似度高 | 都是小物件，YOLO 多类检测的常见难题，关注 per-class AP |
| kitchen_waste 仅垃圾类来源是整图框 | 无真实检测框标注，但 V1 E52 已达 0.972 AP50 |
