# 遥控目标速度、档位曲线与软制动改造计划

## Summary
现有系统已经具备遥控链路、档位限制、PI 速度闭环和目标 RPM 斜坡，能够支撑这次改造。需要补齐的是：更明确的油门到目标速度曲线、分档加减速、油门回中阻尼减速，以及急停下的限流软制动/保持逻辑。

## Key Changes
- `master_bridge` 输出带 `brake` 的 intent，油门回中自动进入刹车态。
- `chassis_driver` 继续做控制源仲裁，并在急停释放时增加“回中 + 低轮速 + 反馈有效”门控。
- `chassis_core` 负责档位曲线、目标 RPM 映射、分档斜率、普通阻尼减速和急停软锁止。
- `phase1_params.yaml` 补齐分档曲线、分档斜率和软制动参数。

## Test Plan
- 低/中/高档油门曲线单调性验证。
- 油门回中时减速斜率与目标 RPM 衰减验证。
- 急停锁存、急停释放条件、软制动电流上限验证。
- 实车低速台架测试后再放开中高档。

## Assumptions
- 普通刹车由油门回中触发。
- 急停采用限流软制动，不假设有独立机械刹车。
- 保持旧 intent JSON 兼容，优先保证调试期可落地。
